# Лаб 1 — Playwright UI автомат тест

**Нэр:** Дэлгэр Хоролмаа

**Оюутны код:** B222270835

## Хийсэн ажил
Saucedemo.com дээр Playwright ашиглан 3 тест бичсэн: (1) зөв хэрэглэгчийн login болон logout, (2) буруу нэвтрэлтийн мэдээллээр оролдоход алдаа гарахыг шалгах, (3) locked out хэрэглэгчээр нэвтрэхийг оролдоход алдаа гарахыг шалгах. Мөн Playwright-ийн codegen хэрэгслийг туршиж, өөрийн бичсэн кодтой харьцуулсан, санаатайгаар тест унагаж trace ашиглан алдааг олсон.

## Selenium ба Playwright харьцуулалт
Playwright дээр элемент бэлэн болтол auto-wait тул гараар wait бичих шаардлага гараагүй, Selenium дээр ийм зүйлийг ихэвчлэн гараар хийдэг. Нэг тест бичихэд Chromium, Firefox, Webkit гурван browser дээр зэрэг ажиллуулсан нь надад тохиромжтой санагдсан — Selenium дээр ийм зэрэгцээ ажиллагааг тохируулахад илүү нэмэлт тохиргоо хэрэгтэй болдог. Playwright-ийн trace viewer гэдэг хэрэгсэл нь тест яагаад унасныг алхам алхмаар харуулдаг тул алдаа хайхад их хялбар байсан. Playwright-ийн codegen хэрэгсэл нь хэрэглэгчийн хийсэн үйлдлийг шууд код болгож бичдэг нь надад шинэлэг санагдсан, гэхдээ энэ нь зөвхөн үйлдлийг л бичдэг бөгөөд ямар ч шалгалт (assert) нэмдэггүй тул би өөрөө бүх expect() мөрүүдийг гараар нэмэх шаардлагатай байсан. Playwright-ийг Node.js орчинд суулгах, тохируулах нь надад харьцангуй энгийн санагдсан.
