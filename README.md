# Лаб 1 — Playwright UI автомат тест

**Нэр:** Дэлгэр Хоролмаа
**Оюутны код:** B222270835

## Хийсэн ажил
Saucedemo.com дээр Playwright ашиглан 3 тест бичсэн: (1) зөв хэрэглэгчийн нэвтрэлт болон гарах, (2) буруу нэвтрэлтийн мэдээллээр оролдоход алдаа гарахыг шалгах, (3) түгжигдсэн (locked out) хэрэглэгчээр нэвтрэхийг оролдоход алдаа гарахыг шалгах. Мөн Playwright-ийн codegen хэрэгслийг туршиж, өөрийн бичсэн кодтой харьцуулсан, санаатайгаар тест унагаж trace ашиглан алдааг мөшгисөн.

## Selenium ба Playwright харьцуулалт
Playwright дээр элемент бэлэн болтол автоматаар хүлээдэг (auto-wait) тул надад гараар wait бичих шаардлага гараагүй, харин Selenium дээр ийм зүйлийг ихэвчлэн гараар хийдэг гэж уншсан. Нэг тест бичихэд Chromium, Firefox, Webkit гурван browser дээр зэрэг ажиллуулсан нь надад тохиромжтой санагдсан — Selenium дээр ийм зэрэгцээ ажиллагааг тохируулахад илүү нэмэлт тохиргоо хэрэгтэй гэдгийг мэдлээ. Playwright-ийн trace viewer гэдэг хэрэгсэл нь тест яагаад унасныг алхам алхмаар, дүрстэй харуулдаг тул алдаа хайхад надад их хялбар байсан. Мөн Playwright-ийн codegen хэрэгсэл нь хэрэглэгчийн хийсэн үйлдлийг шууд код болгож бичдэг нь надад шинэлэг санагдсан, гэхдээ энэ нь зөвхөн үйлдлийг л бичдэг бөгөөд ямар ч шалгалт (assert) нэмдэггүй тул би өөрөө бүх expect() мөрүүдийг гараар нэмэх шаардлагатай байсан. Playwright-ийг Node.js орчинд суулгах, тохируулах нь надад харьцангуй энгийн санагдсан.
